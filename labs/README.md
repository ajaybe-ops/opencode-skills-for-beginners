# Labs

Three exercises that take about 45 minutes total. Do them in order — each one assumes the previous worked.

| Lab | Skill being practiced | Time |
| --- | --- | --- |
| [Lab 1 · Install and invoke](lab-1-install-and-invoke.md) | discovery, `@id`, verification | 10 min |
| [Lab 2 · Write a real skill](lab-2-write-a-skill.md) | frontmatter, descriptions, workflow | 20 min |
| [Lab 3 · Debug a broken skill](lab-3-debug-a-broken-skill.md) | the six-cause checklist | 15 min |

Solutions are in [solutions.md](solutions.md). Try each lab before reading them — the labs are diagnostic, and peeking skips the part that teaches you.

## Ground rules

- Work in a scratch folder, not your real project, until a lab says otherwise.
- Start a **new session** after every file change.
- If a lab fails, do not edit the skill until you have written down which of the six causes you suspect. That habit is the actual takeaway.
